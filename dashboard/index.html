    Price-check overlay Windows
    Press Ctrl+D on an item in game (Ctrl+Alt+D to keep it open and tick rows) and a price popup appears: poe.ninja, our craft estimate and, if you switch it on, live prices from the official trade site (one search per item you copy, like Exiled Exchange 2 does). Run the game in windowed fullscreen. The only keys it ever sends are the ones you ask for: Ctrl+Alt+C to copy the item when you press Ctrl+D, and your own chat commands (F5 /hideout and so on).
