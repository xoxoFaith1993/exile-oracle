    Wishlist
    
      
    Chase items you want to keep an eye on. Leave the price empty to just track an item, or set a target to buy or sell at: then you get an alert when it reaches your target, when the price forecast says it's heading there this week, or when new patch notes call a move for it. An item at your target also becomes the omen on Home. The alerts land on the Alerts page (filter: Wishlist).

    Connect to Claude optional
    Exile Oracle is made to be used with Claude: connect it once, then ask things like "what should I farm", "how close am I to the top 1%" or "how do I craft this". Everything else works without it. How to use it with Claude ↗
    
      
    
    
    Question chips
    The ready-made questions on every page ("Ask the Oracle: …"). A click opens your AI app with the question already typed in: you press Enter. (No AI app lets another program send for you; Claude shows a short safety note on prompts that arrive this way.)
    
      
    
    
    Other AI apps connectors
    Exile Oracle's tools work in any app that speaks MCP, not just Claude. Connect one and ask it the same things. The Oracle feed in the Build Lab shows which app is asking.
    
      
    
    
    Price-check overlay Windows
    Press Ctrl+D on an item in game (Ctrl+Alt+D to keep it open and tick rows; both can be changed below) and a price popup appears: poe.ninja, our craft estimate and, if you switch it on, live prices from the official trade site (one search per item you copy, like Exiled Exchange 2 does). Run the game in windowed fullscreen. The only keys it ever sends are the ones you ask for: Ctrl+Alt+C to copy the item when you press Ctrl+D, and your own chat commands (F5 /hideout and so on).
    
      
    
    
    Game data updates itself
    Exile Oracle keeps what it knows about the game (zones, atlas, campaign rewards, research) up to date by itself: after a patch, a small data update arrives within hours, with nothing to install. App updates still come with the banner.
